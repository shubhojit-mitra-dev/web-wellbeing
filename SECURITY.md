# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Web Wellbeing seriously. If you discover a security vulnerability, please follow these steps:

1. **Do not** report security vulnerabilities through public GitHub issues.
2. Email security reports directly to the maintainers at `shubhojitmitra.dev@gmail.com`.
3. Include detailed steps to reproduce the issue, proof of concept code, and potential impact.

### Response Expectations

- **Initial Response**: Within 48 hours.
- **Triage & Status Update**: Within 7 business days.
- **Fix & Disclosure Schedule**: Security patches will be prioritized and published promptly.

Thank you for helping keep Web Wellbeing safe for everyone.
